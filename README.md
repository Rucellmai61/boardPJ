## Introduction

Trust Wallet Core is a cross-platform library that implements low-level cryptographic wallet functionality for many blockchains. Most of the code is C++ with a set of strict exported C interfaces. The library provides idiomatic interfaces for all supported languages (currently Swift for iOS and Java for Android).

## Usage

If you want to use wallet core in your project follow these instructions:

* For building locally, or using Docker image, see the [Build Instructions](wallet-core/developing-the-library/building).
* For trying out, e.g. testing key management and address derivation, see the [WalletConsole utility](wallet-core/developing-the-library/walletconsole).
* If you want to include Wallet Core in your project, see the [Integration Guides](wallet-core/integration-guide). Start with the overview of the most common wallet operations ([Usage Guide](wallet-core/integration-guide/wallet-core-usage)), and see the platform-specifc guides for [iOS](wallet-core/integration-guide/ios-guide) and [Android](wallet-core/integration-guide/android-guide).
* We have a [FAQ](wallet-core/faq) list may already answer some of your questions.
